### 1. DFS（深度优先搜索）

深度优先搜索算法（Depth First Search，简称DFS）：一种用于遍历或搜索树或图的算法。 沿着树的深度遍历树的节点，尽可能深的搜索树的分支。当节点 $v$ 的所在边都己被探寻过或者在搜寻时结点不满足条件，搜索将回溯到发现节点 $v$ 的那条边的起始节点。整个进程反复进行直到所有节点都被访问为止。

翻译成人话，就是一条道走到黑，撞墙了再回头换个岔路走。

			dfs(i);//基于此点继续做深搜
		}
	}
}

### 2. BFS（广度优先搜索）

广度优先搜索（Breadth First Search，简称BFS）：遍历图存储结构的一种算法。广度优先搜索以队列（queue）作为核心，其搜索核心是从始结点开始，寻找一步到达的合法可行点（可能存在其他条件限制），并加入队列，然后弹出始结点，由依次对队列中的结点执行寻找操作，直至队列为空。

所谓宽度优先．就是每次都尝试访问同一层的节点． 如果同一层都访问完了，再访问下一层。
这样做的结果是，BFS 算法找到的路径是从起点开始的 **最短** 合法路径。换言之，这条路径所包含的边数最小。
在 BFS 结束时，每个节点都是通过从起点到该点的最短路径访问的。
BFS经常用来解决无权值的最短路径问题。

简单来说，就是按顺序搜索，可以想象成水流从上到下流下来（什么雷霆比喻），也可以看做是图上火苗传播的过程：最开始只有起点着火了，在每一时刻，有火的节点都向它相邻的所有节点传播火苗。

## 二. 什么是网络流？

网络流是**带容量限制的有向图流量分配模型**，常用于最大流、最小割、最小费用最大流等优化问题。其核心思想是：在满足**容量限制**与**流量守恒**的前提下，通过不断寻找**增广路**来优化流量分配。

看不懂没关系，想象一下，你有一个自来水管道网络。水从一个叫“源点”的地方出发，要流到另一个叫“汇点”的地方。管道有粗细（容量），水不能超过管道的粗细。**网络流** 要研究的就是：在这个管道网络中，水最多能从源点送到汇点多少吨。
而 **网络最大流** 就是那个“最多能送多少吨”的答案。~~//感谢D老师~~



网络最大流的一般形式就是在一个有向图中，有源点 $S$ 和汇点 $T$ ，每条边有流量 $f$ 和容量 $c$ ，可行流应满足：

1. 每条边的流量 $f\leq c$ 
2. 除源点和汇点外，每个点的流入总量 $=$ 流出总量

求在所有可行流中的最大流量（最大流）



我们介绍一些**基本概念**：

**最大流**：从源点流向汇点的最大流量。
**增广路**：一条从源点到汇点的所有边的剩余容量大于零的路径。
**残留网**：在已分配部分流量的基础上，为每条原边构造两个方向的有向边——正向边剩余容量为原容量减当前流量，反向边容量等于当前流量。由这些剩余容量边与原反向边共同构成的图，称为残留网（或残余网络）。它反映了在当前流量下，还能继续增广或调整的潜力。随着流量更新，残留网也会动态变化。

这个反向建边的操作，我们可以理解成这个水挤回去重新流了，算是一种贪心的反悔机制。这种思想在接下来的两个算法中都有用到。

## 三. 解决网络流问题的两种经典算法

*篇幅有限，本篇仅介绍网络最大流问题中最经典的 Edmonds-Karp 和 Dinic 算法。*

### 1. Edmonds-Karp算法—— 老老实实一探到底

- **做法**：每次用 BFS老老实实找一条**最短**的能通水的路径（一次处理一条增广路），然后灌水（减去该路径能通过的最大水量）。之后继续从起点重新 BFS 找下一条。
- **特点**：一次只找一条路，找到就重新开始。思路简单，但效率不高，适合小网络。
- **时间复杂度**： $O(n m^2)$ //这里n是点数，m是边数

大概的思路是：先建图，保存正向边的同时建对应的反向边（容量为0）。反复通过BFS寻找增广路直到无增广路可找，只要找到一条增广路就更新残留网，累计可行流计算最大流。

不多说，见代码：

```c++
#include<bits/stdc++.h>
#define ll long long//本代码会出现ll&int数据类型混用情况，不是很严谨，但是能AC（划掉，不建议大家这么干。
using namespace std;
ll n,m,s,t,mf[5005],pre[5005];//mf数组存储从源点s到当前点增广路上的容量上限（最小容量）
struct node{
	ll u,v,w;
};
vector<node> e;
vector<ll> h[5005];
ll flow;
bool bfs(){
	memset(mf,0,sizeof(mf));//初始化最小容量
	mf[s]=1e9;//起点最小容量设为正无穷
	queue<int> q;
	q.push(s);//起点入队
	while(!q.empty()){
		int u=q.front();
		q.pop();//正常广搜
		if(u==t) return true;//找到一条增广路，直接返回处理
		for(int i:h[u]){//遍历以u为起点的边的编号i
			int v=e[i].v;//u->v这条边的终点v
			if(mf[v]==0&&e[i].w>0){//没访问过且有容量可走
				mf[v]=min(mf[u],e[i].w);//更新容量上限
				pre[v]=i;//记录前驱的编号，便于后续更新残留网
				q.push(v);//终点入队，继续广搜
			}
		}
	}
	return false;//没找到增广路，结束
}
int main(){
	cin>>n>>m>>s>>t;
	int u,v,w;
	for(int i=1;i<=m;i++){
		cin>>u>>v>>w;
		e.push_back({u,v,w});//建正边
		h[u].push_back(e.size()-1);//h数组保存以u为起点边的编号
		e.push_back({v,u,0});//建反边
		h[v].push_back(e.size()-1);
	}
	while(bfs()){//反复寻找增广路
		int v=t;
		while(v!=s){
			int i=pre[v];//往前倒，找到以v为终点的那条边的编号，更新残留网
			e[i].w-=mf[t];//因为刚找到的增广路已经流完了，所以我们更新正边和反边的容量
			e[i^1].w+=mf[t];//反边的反悔机制。这里^1运算可以找到对应的反边编号。
			v=e[i].u;//继续往前倒（这里写v=e[i^1].v是同样的效果）
		}
		flow+=mf[t];//统计最大流，累加
	}
	cout<<flow;
	return 0;
}
```



### 2.Dinic 算法 —— 聪明的分层向导

- **做法**：
  1. 先用 BFS 对整个网络**分层**（比如源点在第0层，相邻的点在第1层……），形成一个“层级图”。
  2. 然后在层级图上用 DFS（深度优先搜索）**一口气找出多条**能通水的路径，同时灌水。
  3. 重复以上分层、找多条路的过程，直到无法分层。
- **特点**：一次分层后，可以同时找到很多条路径，效率高很多，适合大网络或复杂网络。
- **时间复杂度**： $O(n^2 m)$ //一般是这个，加弧优化能更快

思路：

示例代码：~~（纯手工，非遗制造，无任何AI添加，匠心代码，致敬非遗传承人）~~

```C++
#include<bits/stdc++.h>
#define ll long long//不开long long见祖宗 
using namespace std;
ll n,m,s,t,d[5005],flow;//d数组存储节点u的层次
struct node{
	ll u,v,w;
};
vector<node> e;
vector<int> h[5005];
bool bfs(){
	memset(d,0,sizeof(d));
	d[s]=1;//源点s在第一层 
	queue<int> q;
	q.push(s);
	while(!q.empty()){
		int u=q.front();
		q.pop();
		for(int i:h[u]){
			int v=e[i].v;
			if(d[v]==0&&e[i].w>0){//v没被访问过且可以被访问（容量不为空） 
				d[v]=d[u]+1;//分层 
				q.push(v);
			}
		}
	}
	return d[t]!=0;
}
ll dfs(int u,ll mf){//寻找增广路和更新残留网同时进行
	if(u==t) return mf;//到达终点返回，mf存储u能够流出的最大流量
	ll sum=0;//存储从u流出的实际流量和 
	for(int i:h[u]){
		int v=e[i].v;
		if(d[v]==d[u]+1&&e[i].w){//遵循bfs的层数规则且有容量，可以被访问 
			ll f=dfs(v,min(mf,e[i].w));//基于v做深搜，找到最大流量 
			e[i].w-=f;//更新边的容量
			e[i^1].w+=f;
			mf-=f;//更新当前点的剩余流量 
			sum+=f;//更新流出总流量
			if(mf==0){//当前点没有流量可以流了 
				break;
			}
		}
	}
	return sum;
}
int main(){
	ios::sync_with_stdio(false);
	cin.tie(0);cout.tie(0);//神秘保命加速咒语，喜欢用输入输出流的小伙伴不要错过 
	cin>>n>>m>>s>>t;
	ll u,v,w;
	for(int i=1;i<=m;i++){
		cin>>u>>v>>w;
		e.push_back({u,v,w});//建边，一样的操作 
		h[u].push_back(e.size()-1);
		e.push_back({v,u,0});
		h[v].push_back(e.size()-1);
	}
	while(bfs()){//对点分层，寻找增广路 
		flow+=dfs(s,1e9);//起点最小容量设为正无穷；累加每次的流量 
	}
	cout<<flow;
	return 0;
}
```
