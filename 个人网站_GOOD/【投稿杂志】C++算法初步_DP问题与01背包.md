## 什么是DP？
DP，即动态规划，是一种通过把原问题分解为相对简单的子问题的方式求解复杂问题的方法。

这么说是不是有点蒙圈啦？那我们来举个栗子：  
> 我们知道，在香芋楼里有很多的楼梯。这天，要在香芋楼里上课的海知滨同学在严肃爬楼梯。  
> 由于耐克中学的学生非常注重体育锻炼，海知滨的腿非常长，所以他爬楼梯时一次性可以跨一节或者两节台阶。  
> 他想要知道想要爬n阶台阶一共有多少种方法。只要你告诉了他，他就会祝福你下次温丝黛得A5哦~

好啦，乍一看这个问题是不是很复杂？假如香芋楼很高，如果我们去枚举每种方案，不敢想象在世界毁灭之前能不能干完。那这个时候我们就要用到这个妙妙工具——动态规划（DP）了。

我们说，DP是一个可以把复杂问题拆分成小问题来解决的方法。那么对于这个问题，我们可以这样想：  

当n=1时，只有一种方法：1阶  
当n=2时，有两种方法：1阶+1阶，或者2阶。   
当n=3时，有三种方法：1阶+1阶+1阶，1阶+2阶，2阶+1阶。  

欸，我们可以发现，当我们走到第 i 阶的时候，可以由上一个状态走1阶或者走2阶转移过来。也就是说，如果我们用数组$f[i]$（没学过数组的同学可以把这个想象成一个函数）来表示到第i阶的时候一共有多少种方案数，那么我们可以写出来一个式子，我们叫它 **“状态转移方程”**：

**$f[i]=f[i-1]+f[i-2]$ ,其中 $f[1]=1,f[2]=2$**

这个式子是什么意思呢？就是我们走到第i阶时的方案数等于走到第i-1阶时的方案数与走到第i-2阶时的方案数之和。走到第i-1阶时，我们再走1阶到达i；走到第i-2阶时，我们再走2阶到达i。也就是说，我们统计了走到第i阶时通过走一阶上来和走两阶上来两种情况的方案数之和，而在算$f[i]$之前，以前的方案数（也就是$f[i-1]$和$f[i-2]$）我们已经统计过了，可以直接使用。

OK，我们已经推导出了状态转移方程，我们发现这个题的计算方法好像和斐波那契数列一样呢！o(*￣︶￣*)o

**主函数代码：**
```cpp
int main()
{
	cin>>n;
	f[1]=1,f[2]=2;
	for(int i=3;i<=n;i++)
	{
		f[i]=f[i-1]+f[i-2];
	}
	cout<<f[n];
	return 0;
}
```
像这样，DP问题一般的解题步骤是：  
1.注意到这是一个复杂的问题，不能用贪心解决。  
2.可以化解为小问题解决。  
3.考虑用DP，列出状态转移方程。

当然，DP也不是万能的神，只有在满足以下条件时才可以使用：最优子结构，无后效性和子问题重叠。这里我就不解释啦，感兴趣的同学自己去查~

## 01背包
接下来，才是本篇文章的重头戏——**背包问题之01背包**。

先说这个01背包是什么 ~~看起来和二进制有关实际上一点关系都没有~~。01背包，实际上指的是一类题目，大体意思就是：
> 有 $n$ 个物品和一个容量为 $W$ 的背包，每个物品有重量 $w_{i}$ 和价值 $v_{i}$ 两种属性，要求选若干物品放入背包使背包中物品的总价值最大且背包中物品的总重量不超过背包的容量，输出最大价值。

PS：01背包里“01”的含义就是不买or买一件。

~~为了完成主编大人让我风格幽默一点的任务~~，我们来举个现实的栗子：

> 轰轰烈烈的耐克中学大义卖开始了！这里有$n$件商品：校服熊、校服熊挂件、明信片……每件商品的价格为$w_i$。  
> 何芝津同学看的眼睛都花了，十分心动。可是，由于无形的大手，她每件商品只能最多购买一次。  
> 她在心中默默打分，对每件商品有一个心动值$v_i$。  
> 但是，她这个月的零花钱已经快见底了，她在想能不能在预算范围$W$内购买商品，使得心动值的总和最大。请你输出这个最大心动值总和。

乍一看，这太难了。我怎么知道我是都买心动值最大的还是都买价钱最小的这样数量多心动值说不定就大又或者两者都不是最优解呢？~~（长难句起手）~~ 这时候，就要请**DP**大人来帮忙了。

把大问题化解为小问题，我们用$f[i][j]$来记录在只能购买到第$i$件商品，预算为$j$的情况下的最大心动值总和。

让我们来列状态转移方程！

我们考虑目前状态可以由什么状态转移而来。  
我们在买到第$i-1$个商品后，如果我们没有买第$i$个商品，那么有$f[i][j]=f[i-1][j]$，心动值不发生变化；  
如果我们买了第i个商品，那么我们上一个状态背包（预算）就得给这次购买留下容量。所以我们要判断$j$是否大于等于$w[i]$（上次购买是否成立）。如果满足，有$f[i][j]=f[i-1][j-w[i]]+v[i]$，表示购买了第$i$件商品，$f$数组加上对应心动值。解释一下，这个式子说的是在买到第$i-1$件商品时，背包容量为$j-w[i]$时的最大心动值再加上这次购买第$i$件商品获得的心动值的和。这样，刚好满足$f[i][j]$数组的定义。  
最后，我们在这两种方案中取最大值。

所以，我们可以得到

**状态转移方程：**  
$f[i][j]=max(f[i-1][j],f[i-1][j-w[i]]+v[i]),j≥w[i]$

**初始化：**  
在我们商品数为0时，总心动值为0；  
在我们背包容量为0时，总心动值为0。  
全部初始化为0即可。

**主函数代码：**
```cpp
int main()
{
	cin>>n>>W;
	for(int i=1;i<=n;i++)
	{
		cin>>w[i]>>v[i];
	}
	for(int i=1;i<=n;i++)
	{
		for(int j=1;j<=W;j++)
		{
			f[i][j]=f[i-1][j];
			if(j-w[i]>=0){
				f[i][j]=max(f[i][j],f[i-1][j-w[i]]+v[i]);
			}
		}
	}
	cout<<f[n][W];
	return 0;
}
```

这一类题目的难点就是：你得发现这题是一个01背包。一旦注意力惊人发现了以后，这题就好做了。
